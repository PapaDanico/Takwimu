Rules: "provisional" is every value with no review record in force (values the data file itself marks as disputed are included and also counted under "disputed"). Source tier: the observation's own field, else the cited source's recorded tier, else a rule on publisher, title and address (`TIER_RULES` in `scripts/census.js`; counted under "inferred" in the basis column). Missing metadata counts a value once per field; "pub. date" is missing when no cited source records a date, and "not stated" (the document prints none) is shown separately. Nulls count values that are null (not empty lists).
